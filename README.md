# Design Worlds

A library of live UI designs. `index.html` is a thin gallery; every design is its own folder.

```
index.html          gallery shell (search, filters, detail view)
app/                gallery code: search.js, detail.js, app.js, app.css
designs/<id>/       one design per folder, self-contained
  design.json         metadata, palette, type, motion, tokens (drives search and the notes)
  sample.html         the live sample markup
  sample.css          its styles, every class prefixed (e.g. bd-)
  sample.js           optional behaviour
  spec.md             optional long-form spec
  DESIGN.md           generated, portable spec to drop into any project
designs/_template/  copy of what a new design starts from
data/               generated by the build, do not edit
scripts/            build.mjs, new.mjs
```

## Add a design

```
node scripts/new.mjs my-world "My World"
node scripts/build.mjs --watch     # rebuilds on save
```

Open `index.html`, no server needed. Edit the files in `designs/my-world/`; the gallery picks it up on the next build.
`node scripts/build.mjs` also validates every `design.json` and prints what is missing.

## Reuse a design elsewhere

- Copy `designs/<id>/DESIGN.md` into a project (or hand it to an AI) as the design brief.
- Copy the whole folder: `sample.html`, `sample.css`, `sample.js` run standalone.
- In the gallery, **Download sample.html** gives one self-contained file.

## Search

Type to match name, use, feel, colour name or hex, font and description. Filters combine (any within a group, all across groups) and show live counts. `/` focuses search, `Enter` opens the top result, arrow keys move between designs, `Esc` goes back. The URL holds the search, so a filtered view can be shared.
