# Work (/work)

Scope: the work-history page, converted from the retired Swiss style into the drawing set. Mode: Experience (portfolio record). Audience: prospective clients checking delivery evidence per role. Action: open a role's notes; finish at "Start a project". Proof: the five roles in constants.ts (WORK_EXPERIENCE), real metrics only, PBM client stays anonymised.

User asked for something bolder than Home while keeping the same design principles. Chosen composition: "Five sheets, run sideways" (sketch: .impeccable/mocks/decision/sheet-run.html).

## Direction contract

THESIS: The work record is a drawing set laid on a plan chest and slid past one sheet at a time. Vertical scroll pins the page and travels sideways through a register sheet, five role sheets in date order, and one blank sheet for the visitor's system. Refuses the stacked timeline of cards.

OWN-WORLD: Home's drawing set unchanged: cyanotype ground with the 32/160 grid, framed sheets on Deep Ground, Barlow Condensed caps, Barlow notes, line work plotting in as each sheet slides in, one red stamp.

STORY: The visitor sees the whole register first, then each role at full scale: who, when, the system drawn, the real metric, the tools. The timeline ends at "now", and the next sheet is blank: theirs. They press Start a project.

FIRST VIEWPORT: Top bar; the register sheet filling the left ~80% (WORK at hero scale, outlined "2024 — now", the five-row drawing register as jump links); the next sheet peeking at the right edge; a full-width scale bar along the bottom with five role lanes and a red "here" marker that travels as you scroll.

FORM: Sheet run (pinned horizontal travel), position 7 of my ordered list, seed key 5f2a0ca7. Signature interaction: scroll-linked sideways travel with per-sheet plot-in and the scale-bar marker sliding through real dates; drawing/notes toggle on each sheet. Falls back to a vertical stack on narrow, short or reduced-motion screens.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
